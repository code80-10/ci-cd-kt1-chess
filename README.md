# КТ №1 — Локальная разработка. Линейные алгоритмы

Учебная работа по дисциплине «Автоматизация разработки программного обеспечения (CI/CD)». C++17, задача №2.25 по формулировке преподавателя.

## Условие

На шахматной доске расположены белый король, чёрная ладья и чёрный слон. Определить наличие угрозы королю и атакующие фигуры с учётом перекрытия линий атаки.

Ввод: шесть целых чисел `xK yK xR yR xB yB`, каждое от 1 до 8. Фигуры должны занимать разные клетки. Проверяется текущая атака. После первых шести токенов дополнительные токены не обрабатываются.

## Сборка из PowerShell

Требуется GCC UCRT64 (MSYS2) с поддержкой C++17. Команды выполняются в корне проекта. Если MSYS2 установлен в другом каталоге, укажите соответствующий путь к g++.

```powershell
New-Item -ItemType Directory bin -Force | Out-Null
& 'C:\msys64\ucrt64\bin\g++.exe' -std=c++17 -Wall -Wextra -pedantic -static -finput-charset=UTF-8 -fexec-charset=UTF-8 src\main.cpp -o bin\chess.exe
```

Статическая линковка позволяет запускать EXE без добавления путей библиотек в PATH. В Windows программа выбирает UTF-8 только для текущей консоли.

## Запуск

```powershell
.\bin\chess.exe
```

Пример ввода: `4 4 4 1 1 1`. Ответ: `Королю угрожают чёрная ладья и чёрный слон.`

```powershell
'8 4 1 4 5 4' | .\bin\chess.exe
```

Ответ: `Угрозы королю нет.` Слон перекрывает ладью. При корректных данных код завершения 0, при ошибке ввода — 1.

## Тестирование

Требуются Python 3 и GCC UCRT64 по указанному выше пути. Дополнительные библиотеки Python не нужны.

```powershell
New-Item -ItemType Directory bin,evidence,work\tmp -Force | Out-Null
python tests\run_tests.py
```

Скрипт собирает программу и запускает 30 проверок: атаки ладьи и слона, двойная угроза, перекрытия, продолжения линий, границы и ошибки ввода. Журналы создаются локально в `evidence/`. Для текущего исходного кода сохранён результат 30/30 PASS.

## Файлы

- `src/main.cpp` — полный рабочий исходный код.
